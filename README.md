## 🧠 CNN-Based Deep Learning Model for Malaria Prediction

A CNN-based deep learning model for malaria prediction using microscopic blood-cell images.

### 📌 Project Overview

This project uses Convolutional Neural Networks (CNNs) to classify microscopic blood-cell images and assist in preliminary malaria screening.

### 🚀 Highlights

- Trained and evaluated on **27K+ microscopic blood-cell images**
- Achieved **96.8% classification accuracy**
- Implemented image preprocessing and augmentation
- Built an end-to-end computer vision pipeline
- Performed model training and evaluation

### 🛠️ Tech Stack

`Python` • `TensorFlow` • `Keras` • `CNN` • `OpenCV` • `NumPy`
